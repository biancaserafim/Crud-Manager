# CRUD Manager

Projeto desenvolvido para a disciplina de Tecnologias para Web II — IFSULDEMINAS, Campus Machado.

## Funcionalidades

- Cadastro de fornecedores
- Cadastro de produtos
- Sistema de login
- Paginação nos cadastros

## Tecnologias

- Java
- Servlets
- JSP
- JavaScript
- MySQL
- Tomcat

## Como executar

1. Execute o script `src/main/webapp/WEB-INF/script-sql.sql` no MySQL.
2. Configure e publique o projeto em um servidor Tomcat.
3. Utilize o contexto `/crud-manager`.
4. Acesse:

`http://localhost:8080/crud-manager`
